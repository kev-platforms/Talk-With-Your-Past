# ⏳ Talk-With-Your-Past

Un simulador espacio-temporal impulsado por Inteligencia Artificial que te permite chatear con tus propias coordenadas del pasado (como el año 2014) o explorar tus líneas temporales del futuro.

## 🌌 La Física detrás del Proyecto
Este proyecto está inspirado en la teoría de la relatividad de Einstein y el concepto del **Universo Bloque (Block Universe)**, el cual postula que el pasado, el presente y el futuro coexisten simultáneamente en un tejido cuatridimensional. Aunque físicamente nuestra conciencia está atrapada en el presente, esta aplicación utiliza datos e IA para "hackear" el bloqueo térmico y generar una ventana hacia tus otras coordenadas temporales.

## 🛠️ Tecnologías utilizadas
* **Frontend:** Streamlit (interfaz interactiva).
* **Cerebro de IA:** Meta-Llama-3-8B-Instruct (procesado a través de los servidores libres de Hugging Face).
* **Diseño de Avatares:** API abierta de DiceBear.
* **Lenguaje de Programación:** Python 3.
